# Project Overview: Uber Operational Performance Dashboard

## Executive Summary
This Power BI project provides an end-to-end operational and financial analysis of Uber's ride-hailing services. Utilizing a primary dataset of 150,000 ride records, the dashboard identifies revenue loss drivers, tracks customer/driver satisfaction ratings, evaluates route high-density hotspots, and analyzes trip completion metrics across vehicle categories.

## Objectives
* Track overall business volume, completed trips, lost bookings, and gross revenue.
* Isolate root causes for ride cancellations across customers and drivers.
* Identify high-volume pickup and drop-off hubs to optimize driver dispatching.
* Assess service quality across different vehicle types using customer and driver rating distributions.

## Scope & Dataset Specifications
* **Total Dataset Volume:** 150,000 bookings
* **Completed Rides:** 93,000 (62.0%)
* **Total Revenue:** $51.85 Million
* **Primary Key Entities:** Booking ID, Customer ID, Vehicle Type, Location Nodes, Financial Values, Cancellation
