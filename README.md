# Project Overview: Uber Operational Performance Dashboard

## Executive Summary
This Power BI project provides an end-to-end analysis of Uber's ride-hailing performance across key operations, customer satisfaction, financial performance, and cancellation mechanics. Designed as a interactive multi-page Power BI dashboard, it translates raw ride logs into actionable strategic insights.

## Project Scope & Data Architecture
* **Dataset Size:** 150,000 total booking entries
* **Timeframe:** Multi-quarter operational tracking (Q1 - Q4)
* **Key Entities:** Bookings, Vehicle Types, Pickup/Drop Locations, Revenue, Ratings, Cancellation Drivers
